# Проект «Товары и категории»

## Реализованный функционал

- `Product` хранит название, описание, цену и количество товара.
- `Category` хранит название, описание и список товаров.
- При создании категорий автоматически подсчитывается общее количество категорий и товаров.

## Тесты

Тесты проверяют инициализацию объектов `Product` и `Category`, а также подсчёт категорий и товаров.

Запустить тесты можно из папки проекта, где находится `pyproject.toml`:

```bash
poetry install --no-root
poetry run pytest
